01 The pipeline

Seven gates.
Zero trust.

Every stage is independently callable. Nothing advances on faith — a candidate becomes an asset only after the bytes decode, hash and pass the rights gate.

02 Why it holds up

Built for machines
that don't guess.

SEC / 01
100%

Verified bytes, or nothing

A file is "downloaded" only after Pillow fully decodes it, the format matches its magic bytes, and the SHA-256 is recorded. HTML dressed as .jpg, corrupt files, bomb-sized payloads — rejected before they ever touch your assets.

  • Streaming downloads with atomic .part → rename
  • MIME + full decode + per-format policy (JPEG/PNG/WebP/GIF, opt. AVIF)
  • Perceptual-hash dedupe across jobs
✓
SEC / 02

Hardened by default

The network is hostile; imgagent treats it that way.

  • SSRF guards: loopback, private, link-local, cloud-metadata ranges
  • DNS-rebinding re-checks on every redirect hop
  • TLS verification never disabled — no debug escape hatch
  • Path-traversal-proof writes; downloads never executed
🛡
SEC / 03

Rights are data, not vibes

License, creator and source page ride on every asset. --require-reuse-rights admits only verified public-domain / licensed material. Unknown never passes the gate — no matter the score.

§
SEC / 04

Idempotent to the core

Kill it mid-run, rerun it tomorrow — stable candidate IDs, resumable jobs, verified files reused, SQLite state that survives restarts. Agents can retry without fear.

∞
SEC / 05

One JSON contract

stdout = exactly one JSON object. stderr = diagnostics. Exit codes 0/1/2/3 mean exactly one thing each. Your parser is 3 lines and never breaks.
